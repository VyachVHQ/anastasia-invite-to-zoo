# Как сохранять ответы приглашённого в Google Таблицу

Это нужно сделать **один раз**. После этого каждый ответ человека будет автоматически
появляться в вашей таблице.

---

## Часть 1. Создаём Google Таблицу

1. Открой сайт **https://sheets.new** — откроется новая пустая таблица.
2. Назови её как хочешь, например «Ответы на приглашение».
3. Эта таблица станет местом, куда будут падать все ответы.

## Часть 2. Добавляем «скрипт», который принимает ответы

1. В таблице сверху нажми меню **Расширения** (Extensions) → **Apps Script** (Скрипт приложений).
2. Откроется новое окно с кодом. **Сотри весь код**, который там есть.
3. Скопируй код ниже и вставь вместо него:

```javascript
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var text = e.postData.contents;
  sheet.appendRow([new Date(), text]);
  return ContentService.createTextOutput('OK');
}
```

4. Нажми значок **💾 Сохранить** (или Ctrl+S).

## Часть 3. Публикуем как «Веб-приложение» (получаем ссылку)

1. Нажми кнопку **Развернуть** (Deploy) вверху справа → **Новое развертывание**.
2. Нажми значок **⚙️** (шестерёнка) → выбери **Веб-приложение** (Web app).
3. Заполни поля:
   - **Execute as** (Выполнять как): **Я** (Me)
   - **Who has access** (Кто имеет доступ): **Все** (Anyone)
4. Нажми **Развернуть** (Deploy).
5. Сайт спросит разрешение:
   - Нажми **Разрешить доступ** (Grant access).
   - Покажется предупреждение «Google не проверил это приложение» →
     нажми **Дополнительные параметры** (Advanced) → **Перейти на «Название проекта» (небезопасно)** → **Разрешить**.
6. Скопируй **URL веб-приложения** (строка вида `https://script.google.com/macros/s/.../exec`).
7. Скопируй этот URL — он понадобится в следующей части.

## Часть 4. Вставляем ссылку в проект

1. Открой файл проекта:
   `src\lib\report.ts`
2. Найди строку:
   ```typescript
   const WEBHOOK_URL = ''
   ```
3. Вставь скопированную ссылку внутрь кавычек. Должно получиться так:
   ```typescript
   const WEBHOOK_URL = 'https://script.google.com/macros/s/ТВОЯ-ССЫЛКА/exec'
   ```
4. Сохрани файл.

## Часть 5. Собираем и загружаем сайт заново

1. Открой терминал в папке проекта.
2. Выполни команду:
   ```
   npm run build
   ```
3. Дождись, пока появится папка **out**.
4. Зайди на **dash.cloudflare.com** → раздел **Drop**.
5. Перетащи папку **out** в окно загрузки.
6. Готово!

---

## Как проверить, что всё работает

1. Открой свой сайт в браузере.
2. Пройди приглашение до самого конца (до экрана «Увидимся»).
3. Открой свою Google Таблицу — там должна появиться строка с датой и ответом.

## Если ответ не появился

- Убедись, что в `report.ts` ссылка вставлена **без лишних пробелов**.
- Проверь, что в настройках развертывания стоит доступ **«Все»** (Anyone).
- Открой сайт в браузере, нажми **F12** → вкладка **Console** — ошибок быть не должно.
